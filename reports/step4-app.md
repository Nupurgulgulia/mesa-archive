# Step 4: The app (2026-10-20)

Next.js 15 + Neon Postgres + Neon object storage + Gemini, running only on this laptop at http://localhost:3000. Start it with **`Start MESA Archive.cmd`**.

## Decisions taken in this step (and why)
| Decision | Why | Downside |
|---|---|---|
| AI = Gemini via your API key (`gemini-3.8-flash`) | Neon's AI gateway returned `paid_plan_required` on your free plan; you supplied Gemini keys | Usage is billed to that Google project; the key was pasted in chat (rotate it when convenient) |
| Of the 3 keys, the 2nd is used | The 1st was rejected as invalid; the 3rd was not tried (one working key is enough) | — |
| Runs locally, bound to 127.0.0.1 | You didn't choose; local is the safe default. The first start listened on every network interface (reachable from the same Wi-Fi), now fixed | Only usable on this computer while it's on; going online later needs Vercel or similar |
| Single password, scrypt hash, signed 14-day cookie | Single user; no third-party auth | Lose the password and you reset it with `npm run set-password` (needs this computer) |
| App uses a separate READ-ONLY storage key (`mesa-app-read`) | The web app can never modify or delete the archive | — |
| Files served from the verified local archive first, bucket second | Fast, works offline, survives Neon changes | — |

## Screens
- **Home:** exam countdowns (Mid Term 34 days, BMM Final 43, End Term 63); what's due, sorted upcoming → overdue → undated; this week's calendar; review queue; weak topics; attendance flags; latest Nexus notices.
- **Courses:** 24 courses by term. Each shows every file (opens from the archive), note (full text inline), link (original plus "saved copy" badge, or "needs Google login"), Drive folders (browsable), recordings (YouTube links, uncertain dates flagged), assignments with status/marks, announcement titles, attendance, outline link.
- **Search:** full text across 357 documents / 6,049 passages (incl. OCR and saved link copies). Best passage per document, highlighted, opens the PDF at the right page. Falls back to "broader matches" when few documents contain every word. Also searches recording, assignment, calendar and item titles.
- **Exam prep:**
  - Topics are built per course from its own material.
  - MCQs, flashcards and short answers are generated by Gemini, each citing the source passages. MCQ options are shuffled so the answer position gives nothing away.
  - Modes: mock test (timed), flashcards, weak topics, review due (SM-2 spaced repetition), plus "Bad question?" to retire a wrong item.
  - Open answers are graded by Gemini against a rubric, the model answer and the source text, or self-graded when AI is unavailable.
  - **Art of Selling** reuses the course exam skill's structure:
    - The mock paper mirrors the SquadStack end-term written parts: A = 20 MCQs, B1 discovery, B3 PSBA pitch, 2× B4 objections, B5 negotiation prep. Marks are scaled to the paper's weights.
    - Grading uses the skill's course tests and banned-word list.
    - **Role-play drills** with Meenakshi (Vyapar), Vikram (Onsurity), Rajesh (Vyapar) and Neha (GoKwik): hidden pains and blockers unlock only with the right questions. Feedback comes in the skill's fixed format, scored out of 30 like B2.
- **Timeline:** classes, exams, events, holidays, building time, assignment deadlines, Nexus notices, MRS and recordings. Filter by term, kind, past/upcoming; jump to today. (149 classes, 37 events and 11 exam slots so far.)
- **Recommendations:** computed on every visit. Areas: assignments (overdue vs. probably-sat-in-class), MRS (weekly TMAY, Resume Stress Test 25 Oct, MRS 2 prep), attendance (AoS 61.5%, AI 68.2%; the 75% threshold is labelled a guess), exams and prep gaps, Specialisation Primer dates, ILS/BSL (opt-in status unknown), office hours (Parth's slots), Startup Leader sessions and other events, archive gaps (3 login-only files, no sync yet).

## Not done / limits
- **The 25-minute voice call (B2) and the voice negotiation (B5) are text role-plays here**, not voice.
- **Some Term 2 courses have no material yet** (AI with Mihirr, B2B Sales, Economics, First Principles Lab, Growth, SQL), so they have no questions until faculty upload and the sync brings the material in. Then run `npm run generate -- <course>` or press Generate in the app.

- **The app is offline-capable for files, not for data:** files come from the local archive, but pages still need the Neon database, i.e. internet.
- **Recommendations are only as fresh as the last capture or sync** (20 Oct).
